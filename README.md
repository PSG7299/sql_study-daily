# SQL Study Daily

Android app that sends 4 reminders a day at random times between 9 am and 10 pm, only on the phone it is installed on. Tapping a reminder opens the SQL Ledger practice page. It also has shortcuts to job searches for PL/SQL and data engineer roles.

## Install

1. On your phone, open the [latest release](../../releases/latest) and download `sql-study-daily.apk`.
2. Open the file and allow "Install unknown apps" when asked.
3. Open the app and allow notifications.

Every push to `main` rebuilds the APK through GitHub Actions.
